# 💰 Premium Expense Tracker Web Application

A modern, feature-rich personal expense tracking application inspired by premium fintech apps. Designed with an elegant UI, powerful analytics, and automatic data persistence to help users manage expenses effortlessly.

---

## ✨ Features

### 🔐 Authentication
- Premium Login Page
- Remember Me
- Secure Local Storage Login
- Logout Functionality

---

### 📊 Dashboard
- Today's Expenses
- Monthly Expenses
- Remaining Budget
- Highest Spending Category
- Total Transactions
- Monthly Expense Bar Chart
- Category-wise Donut Chart
- Recent Transactions
- Spending Insights

---

### ➕ Add Expense
- Indian Rupee (₹) Support
- Custom Expense Categories
- Date-wise Expense Recording
- Optional Notes
- Auto Save
- Dynamic "Other" Category Input

Categories:
- Food
- Travel
- Tour
- Educational Fees
- Stationery
- Shopping
- Medicine
- Other

### 📒 Ledger
- View All Expenses

- Filter by Category

- Sort by Date
- Sort by Amount
- Edit Records
- Delete Records
- Export CSV
